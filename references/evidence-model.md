# 证据模型与评分锚点

在分析聊天、资料、照片和见面复盘时读取本文件。目标不是猜中对方内心，而是根据现有证据做出成本可控、可被后续行为验证的决定。

## 一、证据强度

从强到弱排序：

1. 清楚表达与现实行动：明确答应或拒绝、提出具体安排、按约出现、主动修正计划、兑现承诺。
2. 跨时间的一致行为：连续多次主动、稳定投入、说法和行动一致。
3. 单次互动质量：延伸话题、主动提问、分享细节、接住调侃。
4. 文本风格：回复速度、字数、表情、称呼和语气。
5. 资料与照片审美：只能说明呈现方式，不能直接说明人格、忠诚度和关系意图。

强证据可以改变决策；弱证据通常只能生成假设。一个明确拒绝高于十个表情包，一个具体时间地点高于一句“改天约”。

## 二、证据账本

完整分析至少包含：

- 已发生：可逐字或逐项核对的内容。
- 解释 A：当前最可能的含义。
- 解释 B：另一个合理解释。
- 缺失信息：什么信息会让建议发生变化。
- 验证动作：怎样低成本地区分 A 和 B。

例：

- 已发生：她说这周忙，没有提供替代时间。
- 解释 A：现实确实忙。
- 解释 B：礼貌拒绝。
- 缺失信息：她是否会在之后主动补安排。
- 验证动作：给一次低压力出口；若仍无替代时间，当前按关闭处理。

## 三、五维评分

只有材料能支持时才评分。每个分数必须跟随至少一条证据。

### 互惠兴趣

- 0：明确拒绝、要求停止，或持续躲避。
- 1：礼貌回应但完全单向；多次不回复或只做关闭式回答。
- 2：愿意聊天，但主动性和延伸有限；可能只是社交礼貌。
- 3：稳定互动，有主动提问、分享或轻度暧昧。
- 4：多次主动开启、延续互动，愿意为用户投入时间和注意力。
- 5：清楚表达兴趣，并主动推动见面、再次见面或关系讨论。

### 行动落地

- 0：明确不见、反复失约或现实上不可能。
- 1：只说“有空”“再看”，不提供任何约束和替代。
- 2：原则上愿意，但时间地点仍模糊。
- 3：开始协商日期、地点、距离或交通。
- 4：具体安排已确认，并有正常确认动作。
- 5：按约出现、主动修正变化，或主动提出下一次安排。

### 舒适与边界

- 0：拒绝、恐惧、僵住、明显撤离、无法表达意愿、未成年或明显醉酒。
- 1：防御、勉强、频繁回避，不能自在说“不”。
- 2：中性或信息不足，需要保持普通社交距离。
- 3：放松参与，能表达喜欢与不喜欢，互动无明显压力。
- 4：主动选择靠近或延长互动，并能随时调整边界。
- 5：多次清楚、主动、持续表达当下意愿。该分数仍不代表对任何下一步的预先同意。

### 目标适配

- 0：核心目标冲突，或存在明显不尊重和不可接受的边界冲突。
- 1：长期条件明显不匹配，且无人愿意调整。
- 2：吸引存在，但目标、节奏或现实条件未知。
- 3：初步目标相近，重要分歧尚待验证。
- 4：对关系目标、生活节奏和边界有较高一致性。
- 5：经过时间和现实事件验证，双方能协商分歧并兑现约定。

### 风险成本

分数越高越危险：

- 0：没有具体风险信号；仍保留普通安全意识。
- 1：信息不足或存在轻微成本，需要观察。
- 2：反复含糊、说法小幅矛盾、投入明显不对称。
- 3：身份或动机有实质疑点，出现明显索取、控制、羞辱或多次失约。
- 4：索要钱财、诱导投资、严重身份矛盾、勒索、排他控制或可核实的重要欺骗。
- 5：正在发生诈骗、暴力、威胁、强迫、跟踪、裸聊勒索或重大健康安全风险。

## 四、窗口映射

- 关闭：对方直接拒绝；尚未进入关系时，做过一次不施压的确认仍没有回音；连续两次推迟却都不给新的安排；或边界为 0。已有关系不能机械套用这条早期规则，应结合平时的沟通规律、双方约定和安全情况判断。
- 冷：互惠 0-1，行动 0-1，没有值得继续追加投入的证据。
- 暖：互惠或行动达到 2-3，可以用一次具体动作验证。
- 热：互惠至少 4、行动至少 3、边界至少 3，且没有重大风险。
- 不稳：正负信号冲突、风险成本至少 2，或信息质量太低。

窗口不是人格评价，也不是亲密许可。它只是当前下一步的决策标签。

## 五、置信度

- 低：只有单一信号、单张照片、很短对话或大量信息由用户转述。
- 中：有多个独立信号，时间线基本完整，但还没有现实行动验证。
- 高：跨时间、跨场景的表达和行动一致，并有可核对的现实结果。

不要轻易给高置信度。对陌生人撒谎与否的直觉判断通常很弱；大型元分析发现，无辅助条件下人们识别真话与谎言的平均正确率仅略高于随机水平。因此 Navigator 应看可验证的一致性和风险控制，不扮演“微表情测谎仪”。参见 [Bond 与 DePaulo 的元分析](https://doi.org/10.1207/s15327957pspr1003_2)。

## 六、常见误判

- 把秒回、长回复或性玩笑直接等同于愿意见面。
- 把对方不擅长拒绝误读成“还有机会”。
- 把慢回复直接等同于不忠或养鱼。
- 把一次顺利见面等同于长期适配。
- 把没有身体接触的好约会判成失败。
- 把昂贵消费造成的礼貌配合当成真实兴趣。
- 只找支持自己期待的证据，不写竞争性解释。

## 七、预测写法

预测必须可被下一步观察推翻，例如：

- 当前判断：她有中等兴趣，但行动意愿未验证。
- 可验证预测：给出两个具体日期后，她若有兴趣，通常会接受其中一个或提出替代。
- 推翻条件：再次模糊推迟且没有替代安排。
- 处理：当前窗口关闭，不再追加消息和成本。

不要写“她迟早会回来”“她在测试你”这类无法证伪的结论。
