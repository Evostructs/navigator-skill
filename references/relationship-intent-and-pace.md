# 关系意图与推进速度

当用户谈短期、长期、随缘、速推、playful、关系确认或目标不一致时读取。本模块先分清“要建立什么关系”，再决定“以多快速度验证”，避免把长期误写成拖延，把短期误写成欺骗或施压。

## 一、两根彼此独立的轴

### 轴一：关系意图

| 关系意图 | 成功标准 | 主要验证 |
|---|---|---|
| 短期但坦诚 | 双方都知情、自愿，彼此有吸引并享受当下，没有用虚假未来交换亲密 | 化学反应、轻松玩味、欲望表达、边界、性健康、现实行动 |
| 认真长期 | 不只有吸引，还能在时间和现实压力下共同生活、守约、协商与修复 | 价值观、生活节奏、诚信、冲突、性、金钱、家庭、未来和合作能力 |
| 尚未确定 | 允许真实探索，不假装已有答案，也不借模糊长期占用对方 | 是否愿意继续了解、何时重新确认目标、双方能否接受不确定性 |

### 轴二：推进速度

- 快：信号清楚时尽快邀约、见面、表达兴趣、确认边界和验证适配。
- 中：给双方一定观察空间，但每个阶段仍有现实动作。
- 慢：由现实约束、个人节奏或安全需要决定，不等于低兴趣。

长期可以推进快，短期也可以推进慢。发生亲密关系不证明是短期，没有发生亲密关系也不证明是长期。只依据双方说过什么、约定了什么和持续做了什么判断。

## 二、先问四件事

材料允许时依次确认：

1. 用户现在真正想要短期、长期，还是尚未确定？
2. 对方明确表达过什么？哪些只是用户猜测？
3. 双方希望以多快速度见面、亲密或确认关系？
4. 如果目标或速度不同，是否存在双方都真心接受的交集？

用户说“随缘”时不要自动理解成短期。可以追问：“你是确实还没决定，还是已经知道只想短期，只是不想说得太直？”

## 三、短期模式：轻、快、真

短期关系的成功函数不是“拿下”，而是用较少线上消耗快速确认：双方是否互相吸引、相处是否轻松、边界是否一致，以及是否都愿意继续。

### 默认节奏

信号出现 → 共同玩起来 → 具体邀约 → 现实见面 → 小步表达欲望 → 当下确认边界 → 继续或体面退出

“速推”是减少空聊、幻想和无效等待，在最早且证据足够的窗口转入现实验证。它不是固定几句话、几次见面或几个小时内必须完成什么，更不是用压力绕过拒绝和同意。

### Playful 的组成

- 回接对方刚说过的梗，而不是发送通用段子。
- 对一个无害细节做轻微夸张、假设或角色扮演，让双方都能接着玩。
- 轻挑战一个观点或品味，但不给人格打低分。
- 用具体、带画面的邀约承接聊天，而不是无限问答。
- 真诚表达吸引，语气放松，不把欲望藏成采访或友谊。

只有对方也在延伸、回梗、提问、靠近或推动行动时，才继续增加张力。对方不接、转严肃、回避或身体后撤时，立即降级或停止。

以下不属于 playful：贬低式搭讪、羞辱、制造嫉妒、故意冷暴力、用性经验施压、在公开场合让对方难堪，或把冒犯后的一句“开玩笑”当免责。

### 深层分析的默认关闭

短期场景通常不需要分析童年、情结或投射。先给一句可用表达、一个具体邀约或一次现实验证。只有用户明确要求，或出现反复失控、强烈羞耻和愤怒、自我价值绑定、金钱风险、同一破坏性剧本重复时，才启用 inner-navigation.md。

### 诚实底线

- 不把“我想认真发展”当作获得亲密的手段。
- 不隐瞒已有伴侣、排他约定或会改变对方决定的健康风险。
- 对方明确要长期而用户只想短期时，说明差异；不能靠拖延定义、暧昧承诺或未来画饼继续占用。

## 四、长期模式：快也可以，维度必须多

长期关系不是短期关系的慢动作版本。它可以有强烈吸引、直接表达和快速推进，区别在于需要验证另一组问题：这段关系能不能承载日常、责任、差异和变化。

### 长期承载维度

- 价值观和生活方向：城市、事业、自由、家庭、孩子等重大选择能否协商。
- 诚信与承诺：话和行动是否跨时间一致，排他规则是否明确并被遵守。
- 冲突修复：能否说清需求、承认影响、恢复合作，而不是冷暴力、羞辱或消失。
- 性与亲密：欲望、节奏、边界和健康责任能否坦诚沟通。
- 金钱与责任：消费、债务、支持家庭和风险承担是否透明、可承受。
- 日常合作：时间、卫生、家务、社交、距离和压力下的配合。
- 个体空间：亲密是否仍允许双方保有朋友、兴趣、工作和拒绝能力。

### 快速推进长期关系

可以尽早表达认真意图、密集见面、讨论排他，甚至很快确认关系；但同时要：

- 尽早让彼此看见真实生活，而不只共享浪漫场景。
- 对重要维度直接谈，不靠“以后自然会知道”。
- 用跨场景、跨时间的一致行动验证承诺，不把高浓度情绪当作全部证据。
- 保留独立生活、资金安全和退出能力，避免用快速合并账户、借钱、同居或重大承诺证明真心。

长期的“深”主要来自现实维度和共同经历，不来自无休止的心理分析。需要内在导航时，分析的是用户为何反复做出不利选择，而不是把伴侣变成被解剖的对象。

## 五、目标或速度不一致

先明确差异属于哪一种：

- 目标不同：一方只想短期，另一方明确要长期。
- 速度不同：目标相同，但一方想快、一方需要慢。
- 信息不足：双方都没有说清，只在互相猜。

目标不同且没有真实交集时，最佳动作通常是清楚说明并退出，不教用户隐藏意图。速度不同可以协商下一次可接受的小步，但任何一方都不欠对方某个进度。

## 六、心法：不要把女性想成一张价目表

“女性只看钱”或“女性只看脸”把不同的人压成同一种评分机器，也把关系失败全部外包给不可控条件。钱、外表、身高、职业和社会环境确实可能影响认识机会与第一印象，但它们不能单独解释一个具体人的选择，更不能代替相处体验和目标适配。

如果这种说法进一步把女性描述成天生贪婪、浅薄、应被欺骗或惩罚，它就是物化和厌女式叙事。指出这种叙事即可，不给用户下“厌女症”等心理诊断。

Navigator 把“人格底色”落实为可观察、可训练的表现：

- 喜欢一个人时敢于表达，不把喜欢伪装成讨好、审讯或炫耀。
- 被拒绝时能失望但不报复，不需要贬低对方来恢复自尊。
- 说到做到，边界清楚，也尊重对方的边界。
- 身体、语气和行动相对自然，不因证明价值而过度表演。
- 有自己的生活、欲望和选择，同时能看见对方是一个独立的人。
- 可以玩、可以性感、可以认真，但不靠控制和操纵维持吸引。

这种由内而外的自信比技巧更可迁移，却不能保证得到任何具体对象。吸引仍受个人偏好、时机、现实条件和匹配影响。目标是增加真实的正反馈和选择能力，而不是创造另一种“只要人格好就必胜”的神话。

## 七、建议输出

需要完整分析时明确写出：

- 关系框架：短期但坦诚 / 认真长期 / 尚未确定 / 目标不一致
- 推进节奏：快 / 中 / 慢 / 无法判断
- 当前最该验证的关系维度
- 一条适配该框架的表达或行动
- 对方不接时的退路和停止条件

快速回复不必展开整套框架，但建议必须与已知关系意图一致。
